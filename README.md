# RockPaperScissors
Learning how to make a little game in C++


## How to get started

- install git hub client
- install VS code
- install the Microsoft Visual C++ (MSVC) compiler toolset
- go to GitHub.com and make new repository
- open Developer Command Prompt
- clone to local folder
cd "C:\Users\heiko\OneDrive\Desktop\Source Code"
git clone https://github.com/9000rocks/RockPaperScissors.git
- open VS Code in folder
cd RockPaperScissors
code .
- create a file (i.e., rps.cpp for C++)
- code stuff and test it by compiling and running

## How to play

- compile
- run  ./rps.exe
